## ✨ Features
- Fast, lightweight static landing page
- Responsive design for mobile and desktop
- Clean, modern UI

## 🧱 Tech Stack
HTML5 · CSS3 · Vanilla JavaScript

## 📁 Structure
| Path | Description |
|------|-------------|
| `index.html` | Main page |
| `css/` | Styles |
| `js/` | Scripts |
| `assets/` | Images & media |

## 🚀 Getting Started
```bash
# Just open index.html, or serve locally:
npx serve .
```
