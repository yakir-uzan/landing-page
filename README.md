# דף נחיתה

דף נחיתה לעסק בניית אתרים.

## מבנה הפרויקט

- `index.html` — הדף הראשי
- `css/` — עיצוב (`style.css` + ערכות נושא שונות)
- `js/main.js` — לוגיקה ואינטראקטיביות

## הרצה מקומית

זהו אתר סטטי — אפשר לפתוח את `index.html` ישירות בדפדפן,
או להריץ שרת מקומי פשוט:

```bash
python -m http.server 8000
```

ואז לגלוש אל `http://localhost:8000`.
